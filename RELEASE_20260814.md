# XMON-Grid Publication Release — 2026-08-14

## Release basis

This branch is the publication candidate built from the corrected scientific-validation pipeline. The release is based on the regenerated five-seed experiment (seeds 2026--2030) and the independent physical audit.

## Validated claims

- IEEE 9-, 14-, 30-, and 118-bus benchmark definitions match the canonical PYPOWER/MATPOWER data used by the repository.
- Analytical Jacobian finite-difference maximum absolute discrepancy: approximately `2.7e-9`.
- All 16 repository model tests pass.
- Independent physical audit passes for all four benchmark cases.
- Maximum audited reactive-power equation discrepancy: `2.91e-14` p.u.
- Maximum active-power balance residual magnitude: below `3e-14` p.u.
- Five-seed aggregate for the K=2 quorum mode:
  - F1 = `0.9204 ± 0.0026`
  - Recall = `0.8850 ± 0.0012`
  - FPR = `0.1525 ± 0.0197`
  - MCC = `0.6667 ± 0.0151`
- Attack-wise validation identifies load shift and stealth drift as the principal difficult cases.

## Deliberately excluded claims

The release does not claim the previously reported sub-0.6% FPR, 85.85% recall aggregate, or fixed computational speedup/power-law timing results. Those values are not authoritative for the corrected regenerated run.

The former computational-scaling publication figure is removed from the retained publication figure set.

## Reproducibility

The scientific-validation workflow performs source compilation, canonical benchmark validation, mathematical pipeline checks, unit tests, independent physical checks, publication-claim auditing, IEEE manuscript compilation, and provenance verification. The publication branch reuses the frozen regenerated validation artifacts rather than silently generating a different experiment.

## Limitations

The validation uses canonical IEEE benchmark networks and controlled synthetic attack scenarios rather than field SCADA data. The current evidence therefore supports a reproducible benchmark study, not operational deployment readiness.
